## 两条情境路径

1. `observed_detail`：不要求罕见事故。用日常细节触发**可信但意外的重新理解**；人物据此采取行动，撞上另一个人的正常目标。
2. `minor_chance`：只发生一次小意外；后续升级来自主角的选择。偶然本身不是包袱，选择带来的社会后果才提供戏剧冲突。

每个候选须写明日常目标、触发点、主角选择、与别人相冲的目标和有形后果、具体揭底。提案模型一次给五条，至少两条属于每种路径；独立模型逐一评日常可信度、触发点自然度、冲突和揭底。四项都达到 4/5 且没有致命缺陷，才交给五 Agent 扩写。第二轮提案必须更换第一轮的触发点和应对动作。

这些是**创作约束和模型筛选**，不是人工质量保证。模型可能重复前一轮情境，也可能把弱冲突误判为合格；保存每轮候选和审稿意见，并以新的人工盲评检验效果。来源只进入提示的机制摘要，不把成名段子视为可直接复用的数据集。
