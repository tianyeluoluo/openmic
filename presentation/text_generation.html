Task 02 / Text generation

Two writing routes

25%Source-preserving adaptation

Keep the source event, necessary context and effective reveal.

Change only compatible details. A strong short joke can stay short.

Record the source ID and check which premises make its humor work.

75%Original writing with references

Transfer the expectation change or speaking rhythm into new content.

Start with a funny moment or an experience. Character habits can connect several situations.

Keep reactions, inner thoughts and coincidences when they fit the person and context.

These are default routing probabilities. Adaptation can fall back when no compatible source is found.

Implementation: humor_adaptation.py, humor_generation.py, autogen_v02.py · No generator weight updates

Membership feels cheap

Skipping buys freedom

“三块买一晚自由，这理财收益率还挺高。”

The same logic now excuses avoiding exercise.

03 / Return with a consequence

Renewal reduces daily loss

“现在每天只亏两块五，心里还觉得捡了便宜。”

Renewing exposes the character’s persistent self-justification.

The character’s logic stays consistent while each situation changes its consequence.
